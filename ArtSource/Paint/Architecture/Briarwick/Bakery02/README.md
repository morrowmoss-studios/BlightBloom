# Bakery02 plaster finish

`prepare_plaster.py` reads Bakery01's preserved cleaned package-derived plaster painting. Four soft regions, different orientation and broad low-contrast washes remove obvious repeated panel blemishes without photographic noise. `Plaster_PaintedAtlas02.png` is the working raster; `Plaster_Washes02.svg` is an editable layout/wash guide. The source PNG plus script reproduce the full image. Blender packs the resulting texture; Unity imports its project-owned copy as sRGB 2048 px with mipmaps.

URP Lit, nonmetallic, smoothness .05. Source-specific baked timber AO is excluded. Clay/timber maps are reused unchanged; no approved building or imported image was repainted.
