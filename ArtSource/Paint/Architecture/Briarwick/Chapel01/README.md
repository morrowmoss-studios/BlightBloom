# Chapel01 painting sources

`paint_chapel.py` and source PNGs are editable/reproducible painting sources. Masonry derivative samples the known top-face UV region of the read-only package stone atlas, then reduces contrast/saturation and softens it. Stained glass uses muted broad panes, lead lines, a sun and sprig, plus broad illustrated color transitions. No lettering. Exports go only to Chapel01/Textures. No imported original textures modified.
