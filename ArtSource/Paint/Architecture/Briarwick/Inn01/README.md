# Inn01 wooden shingle grain

`prepare_shingles.py` extracts eight clean shingle-interior grain regions from the installed package roof base color, gently restraining contrast/color and retaining its weathered softness. Original package images are read-only. `SourceRegions.json` records exact crop rectangles. `Shingle_GrainAtlas01.png` is the editable working raster; the script reproduces its regional treatment.

Individual overlapping geometry, rather than a repeating course image, defines the roof. Unity color copy: `Assets/BlightBloom/Art/Architecture/Briarwick/Inn01/Textures/BW_Inn01_Shingle_BaseColor.png`, 1024 px, sRGB, mipmaps. Matte/nonmetallic URP material; no photographic noise or sharpening was added. Source detail is intentionally modest and may require dedicated painting in a later approved finish pass.
